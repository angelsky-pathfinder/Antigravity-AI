# 💻 코다리 — Tension-to-Action Conversion Rate($\text{T2A CR}$) 측정을 위한 데이터베이스 스키마와 $\text{POST /api/track\_action}$ API 엔드포인트 명세를 최종적으로 검토하고, 디자인 변수와의 일관성을 확보할 수 있도록 구현 준비 상태를 점검하라.

⚠️ 코다리 LLM 호출 실패: LLM 모델 로드 대기 240초 초과. 저사양 머신이면 settings.json에서 connectAiLab.streamFirstTokenTimeoutSec 값을 늘리거나 (예: 600), 더 작은 모델로 변경하세요 (gemma2:2b 1.6GB 등).
