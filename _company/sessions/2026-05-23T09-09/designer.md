# 📊 최종 KPI 카드 시각화 프로토타입 (Mockup Specification)

## 1. 디자인 시스템 요약
*   **핵심 컨셉:** 시스템 안정성($S$)과 수익 잠재력($SWRI$)의 대비 극대화.
*   **주요 색상 팔레트:**
    *   **Primary (안정성/기본):** 딥 블루 (`#0A1931` - Deep Blue)
    *   **Accent (경고/리스크):** 크림슨 레드 (`#D93B3B` - Crimson Red)
    *   **Background:** 매우 밝은 회색 또는 순백 (`#F8F8F8`)
    *   **Text/Data:** 딥 블루 (주요 값), 크림슨 레드 (경고 값).

## 2. KPI 카드 레이아웃 정의 (Prototype)
KPI 카드는 세로형(Portrait)을 기본으로 하며, 데이터의 시각적 중요도에 따라 영역을 분할합니다.

### A. 상단 헤더 (Header Area)
*   **목표:** 지표 이름 및 상태 요약 제공.
*   **배경:** 딥 블루 (`#0A1931`)
*   **요소:**
    *   KPI 제목 (가장 큰 폰트, 화이트): `[지표명]`
    *   상태 아이콘/레이블: 현재 상태를 나타내는 작은 인디케이터.

### B. 핵심 지표 영역 (Core Metric Area)
*   **목표:** 가장 중요한 수치($S$ 또는 $SWRI$)를 강조.
*   **배경:** 매우 밝은 회색 (`#F8F8F8`)
*   **요소:**
    *   **메인 값 (Big Number):** 지표의 핵심 수치. 데이터 삽입 시, **안정성($S$)이 낮을 경우 크림슨 레드**로 표시하여 경고를 즉각적으로 알립니다. 안정적일 경우 딥 블루 사용.
    *   **보조 값 (Context):** 비교 대상 또는 목표 대비 지표.

### C. 시각화 및 경고 영역 (Visualization & Risk Area)
*   **목표:** $S$와 $SWRI$의 관계를 직관적으로 표현.
*   **레이아웃:** 수평 막대 그래프 또는 게이지 차트 형태.
    *   **안정성($S$) 시각화:** 딥 블루 계열의 진행 바 (예: 100% 기준).
    *   **수익 잠재력($SWRI$) 시각화:** 크림슨 레드 계열의 대비 바 또는 영역 표시.

### D. 액션 및 해석 영역 (Action & Interpretation Area)
*   **목표:** 데이터에 대한 비즈니스적 해석 및 다음 행동(Action Plan).
*   **배경:** 딥 블루 (`#0A1931`) - 헤더와 통일성 유지.
*   **요소:**
    *   **KPI 해석 (Insight):** 시스템 안정성($S$)과 수익 지표($SWRI$)의 현재 상태에 대한 간결한 분석 문구 삽입 공간.
    *   **Action Item:** 데이터 기반으로 도출된 다음 단계 행동(예: "안정성 확보를 위해 $X$ 조치 필요").

## 3. 레이아웃 좌표 및 스타일 예시 (HTML/CSS Pseudo-Code)

| 요소 | CSS 스타일 | 설명 | 색상 적용 예시 |
| :--- | :--- | :--- | :--- |
| **KPI Container** | `background: #F8F8F8; padding: 20px; border-radius: 12px;` | 전체 카드 배경 | - |
| **Header Bar** | `background: #0A1931; color: white; padding: 15px; text-align: center;` | 상단 헤더 영역 | 딥 블루 |
| **Main Value ($S$/$SWRI$)** | `font-size: 48px; font-weight: bold;` | 핵심 수치 표시 | $S$ 낮으면 크림슨 레드, 높으면 딥 블루 |
| **Risk Bar ($SWRI$ Context)** | `height: 10px; background-color: #D93B3B;` (만약 $S < 0.85$ 일 경우) | 위험 상태 시 시각적 경고 | 크림슨 레드 |
| **Insight Text** | `font-size: 16px; color: #333; margin-top: 15px; border-left: 3px solid #0A1931;` | 비즈니스 해석 영역 | - |

## 4. 데이터 삽입 예시 (Mockup Instance)

**[가정] 시스템 안정성($S$)이 임계값($S_{min}=0.85$) 미만인 경우의 시각화**

*   **KPI 제목:** 시스템 안정성 ($S$)
*   **메인 값:** **$0.72$** (크림슨 레드)
*   **시각화:** $S$ 막대는 크림슨 레드로 채워지며, 그 옆에 경고 아이콘이 표시됨.
*   **해석:** "안정성 임계값($0.85$) 미달. 즉각적인 시스템 안정화 조치가 필요함."
