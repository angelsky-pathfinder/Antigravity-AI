### 📋 다음 액션 아이템 및 역할 분배

**🎯 핵심 과제:** 코다리님이 정의한 `Potential Loss API Schema`를 활용하여, 잠재적인 손실 시나리오 A(가상 위기)에 대한 **'입력 $\to$ 시스템 처리 $\to$ 위험 경고/해결책 제시'**의 3단계 흐름을 구체화합니다.

*   **💻 코다리님 (Developer): 데이터 증명 및 로직 완성**
    *   **액션:** 현재 정의된 `Potential Loss API Schema`를 기반으로, '손실 시나리오 A'에 대한 **최소한의 핵심 테스트 케이스 3가지(데이터 입력값 + 계산 로직)**를 확정합니다. [근거: 에이전트 최근 활동]
    *   **산출물:** PoC 시뮬레이션용 데이터셋 및 API 동작 정의서 업데이트.
*   **🎨 Designer님 (Designer): 스토리보드 구체화 및 인터랙티브 와이어프레임 설계**
    *   **액션:** 코다리님이 확정할 테스트 케이스 3가지의 **데이터 흐름(Input $\to$ Process $\to$ Output)**을 시각적으로 담아내는 **인터랙티브 스토리보드 초안**을 만듭니다. 단순히 레이아웃만 그리는 것이 아니라, 데이터가 어떻게 변화하는지 *흐름 자체*를 보여주는 와이어프레임이 필요합니다.
    *   **산출물:** 3단계 흐름을 담은 시각적 사용자 여정(User Journey) 초안.
