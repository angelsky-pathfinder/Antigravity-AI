## 🚀 MVP 기술 스택 및 PoC 계획 초안

### 1. MVP 목표 정의 (Goal Alignment)

**핵심 목표:** 시스템 안정성($S$)이 고객 유지율($C_{base}$)에 미치는 영향을 측정할 수 있는 최소한의 데이터 파이프라인과 사용자 피드백 루프를 구축하여, $S$ 기반 예측 모델의 초기 신뢰도를 검증한다.

**측정 지표 (KPIs):**
1.  **안정성 측정:** 시스템 안정성($S$)을 시뮬레이션하는 내부 메트릭(Latency, Error Rate 등)을 실시간으로 기록하고 노출한다.
2.  **유지율 추적:** 사용자 행동 데이터(로그인 빈도, 기능 사용률 등)를 수집하여 $C_{base}$의 초기 가설을 검증할 수 있는 피드백 루프를 구축한다.

### 2. 권장 기술 스택 (Recommended Tech Stack)

PoC 단계에서는 **신속한 개발 속도**와 **확장성(Scalability)**, 그리고 **안정성($S$) 확보**에 중점을 두어야 합니다.

| 영역 | 선택 기술 | 선정 이유 (Why?) |
| :--- | :--- | :--- |
| **프론트엔드 (UI/Dashboard)** | **Next.js (App Router)** + TypeScript | 빠른 프로토타입 구축, 서버 컴포넌트를 통한 데이터 안정성 확보 용이, 타입 안정성 극대화. |
| **백엔드 (API/Logic)** | **FastAPI (Python)** | 데이터 처리 및 통계 로직 구현에 Python의 강력함 활용. 높은 성능과 명확한 API 설계가 중요함. |
| **데이터베이스** | **PostgreSQL** | 관계형 데이터의 무결성 보장. 재무 예측 모델에 필요한 정량적 데이터 구조를 안정적으로 저장 가능. |
| **인프라/배포 (Deployment)** | **Docker + AWS/Vercel** | 환경 일관성(Reproducibility) 확보 및 CI/CD 파이프라인 구축의 기반 마련. 시스템 안정성($S$)의 물리적 구현을 시작. |

### 3. PoC 실행 계획 (PoC Execution Plan)

MVP는 다음 세 단계로 구성되어야 하며, 각 단계는 이전 단계의 성공을 전제로 합니다.

#### Phase 1: 데이터 파이프라인 구축 (Focus on $S$ Measurement)
**목표:** 시스템 안정성($S$) 지표를 측정하고 기록하는 핵심 모듈 구현.
1.  **핵심 로깅 레이어 구현:** 모든 API 호출, DB 트랜잭션, 주요 서비스 컴포넌트의 Latency와 Error Rate를 실시간으로 기록하는 엔드포인트(Metrics Endpoint)를 FastAPI에 추가한다. (이것이 $S$ 측정의 물리적 기반).
2.  **데이터 수집 파이프라인:** 로깅된 메트릭을 PostgreSQL 데이터베이스로 안정적으로 스트리밍하고 저장하는 비동기 파이프라인을 구축한다.

#### Phase 2: 사용자 피드백 루프 구현 (Focus on $C_{base}$ Input)
**목표:** 시스템 안정성과 사용자의 행동 간의 상관관계를 측정할 수 있는 최소한의 인터페이스를 구축.
1.  **Engagement Tracker API:** 사용자 세션 데이터(로그인 성공/실패, 핵심 기능 A/B 테스트 참여 등)를 기록하고 조회하는 읽기 전용 API 엔드포인트를 구현한다.
2.  **프론트엔드 시각화:** Next.js 대시보드에 Phase 1에서 수집된 $S$ 메트릭과 Phase 2에서 수집된 $C_{base}$ 관련 데이터를 **KPI 카드 형식**으로 시각화하여 표시한다. (Designer가 정의한 레이아웃 좌표 및 색상 규칙을 엄격히 준수).

#### Phase 3: 예측 모델 연동 및 검증 (Focus on MRR/LTV Validation)
**목표:** 구축된 데이터 흐름을 기반으로 초기 $S$ 가중치를 적용하여 MRR/LTV 예측 모델을 시뮬레이션한다.
1.  **가정 기반 시뮬레이터:** 시스템 안정성($S$)의 변화(예: 5% 성능 저하)를 입력 변수로 넣어, 이에 따른 예상 $C_{base}$ 하락률 및 결과 MRR/LTV 변화를 계산하는 간단한 백엔드 로직을 추가한다.
2.  **최종 보고서:** 시뮬레이션 결과를 바탕으로 "만약 시스템 안정성이 X% 하락하면, $C_{base}$는 Y%로 예측되며 이는 Z개월 내 수익에 미치는 영향"이라는 결론을 도출하는 PoC 보고서를 작성한다.
