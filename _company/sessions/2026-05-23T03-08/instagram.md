## 📊 기술적 로드맵: 참여율 지표($S$ vs $SWRI$)와 데이터 추출 연동 전략

CEO님의 지시를 바탕으로, 최종 스토리보드 및 Poll/Q&A 설계 결과를 실제 참여율 측정 지표($S$ vs $SWRI$)와 데이터 추출 스크립트(`instagram_data_extractor.py`)에 연동하는 구체적인 기술적 로드맵을 작성합니다. 이 로드맵은 콘텐츠 전략과 데이터 파이프라인의 통합을 목표로 합니다.

### 🎯 핵심 목표
콘텐츠 참여 데이터($S$ vs $SWRI$)를 인스타그램 행동 로그 데이터와 실시간으로 매핑하여, 시스템 안정성 및 수익 지표 대비 참여율 변화를 측정하고 다음 콘텐츠 전략에 즉각 반영한다.

### ⚙️ 단계별 기술 로드맵

#### **Phase 1: 참여 지표 설계 (Content Layer)**
이 단계는 인스타그램 게시물 자체에서 데이터를 수집하는 메커니즘을 정의합니다.

1.  **Poll/Q&A 스티커 데이터 표준화:**
    *   각 릴스/피드 콘텐츠에 적용할 Poll 또는 Q&A 스티커의 질문과 선택지를 $S$와 $SWRI$의 대비를 극대화하도록 설계한다 (예: 안정성 vs 수익, 리스크 감수 정도 등).
    *   **출력물:** `sessions/2026-05-23T00-28/instagram_reel_storyboard_final.md` 기반으로 각 릴스에 적용할 Poll/Q&A의 구체적인 프레임과 선택지(Response Set)를 확정한다.

2.  **CTA 전환 로그 정의:**
    *   각 콘텐츠의 최종 Call-to-Action(CTA) 클릭 이벤트가 발생했을 때, 해당 사용자가 어떤 Poll/Q&A에 참여했는지 또는 어떤 정보 요청(DM 등)으로 이어졌는지 추적할 수 있는 메커니즘을 정의한다.

#### **Phase 2: 데이터 파이프라인 통합 (Extraction Layer)**
이 단계는 수집된 참여 데이터를 기존의 데이터 추출 스크립트와 연결하는 기술적 방법을 확립합니다.

1.  **행동 로그 확장:**
    *   현재 `instagram_data_extractor.py`가 도달(Reach) 및 기본 참여 지표를 추출하고 있다면, 여기에 **'참여 인터랙션 메타데이터'** 필드를 추가하여 Poll/Q&A 응답 데이터를 포함하도록 스크립트를 수정한다.

2.  **API 엔드포인트 연동 설계:**
    *   인스타그램 API 호출 시, 단순한 게시물 데이터 외에 해당 게시물에 부착된 인터랙션 레이어(Poll/Q&A)의 반응률을 별도의 엔드포인트로 요청할 수 있도록 Meta Graph API 접근 로직을 확장한다. (필요시, 이 과정은 `instagram_data_extractor.py` 내부에서 구현될 예정.)

3.  **$S$ vs $SWRI$ 매핑 함수 개발:**
    *   추출된 행동 로그 데이터(클릭률, 참여율)와 콘텐츠의 시각적 메시지($S$와 $SWRI$의 대비 강도)를 결합하여 **'참여 효율 지수 ($\text{Engagement Efficiency Index}$)'**를 산출하는 함수를 개발한다.
    $$\text{EI} = f(\text{Click Rate}, \text{Poll Response Ratio}, S, SWRI)$$

#### **Phase 3: 검증 및 피드백 루프 (Feedback Loop)**
이 단계는 측정된 데이터를 기반으로 전략을 개선하는 순환 구조를 구축합니다.

1.  **실시간 대시보드 구축:**
    *   $\text{EI}$ 값을 실시간으로 시각화할 수 있는 간단한 대시보드를 설계한다. 이 대시보드는 $S$와 $SWRI$의 대비가 가장 높은 콘텐츠(예: 컨셉 C)에서 $\text{EI}$가 높게 나타나는지 검증하는 데 사용된다.

2.  **자동 조정 규칙 설정:**
    *   만약 특정 $\text{EI}$ 값이 목표치($\text{Target EI}$)를 하회할 경우, 시스템은 다음 콘텐츠 기획 단계에서 시각적 대비 원칙(딥 블루/크림슨 레드)을 강화하도록 알림을 생성한다.
