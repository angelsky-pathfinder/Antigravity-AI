# 📊 KPI 카드 디자인 시스템 최종 사양 (Mockup Prototype)

## 1. 브랜드 컬러 및 타이포그래피 가이드라인 (확정)

**핵심 컨셉:** 시스템 안정성($S$)과 수익 잠재력($SWRI$)의 대비(Contrast)를 시각적 긴장감으로 표현.

| 요소 | 색상 코드 | 역할/의미 | 적용 비율 |
| :--- | :--- | :--- | :--- |
| **Primary (안정성, S)** | `#003366` (Deep Blue) | 시스템 안정성 ($S$) 영역, 신뢰, 견고함 | 배경 및 주요 프레임 |
| **Accent (잠재력, SWRI)** | `#CC0033` (Crimson Red) | 수익 잠재력 ($SWRI$) 영역, 긴급성, 기회 | 데이터 강조 및 CTA |
| **Neutral (배경)** | `#F4F6F8` (Light Gray/Off-White) | 정보 전달 공간, 시각적 여백 | 카드 배경 |
| **Text (Primary)** | `#1A202C` (Dark Gray) | 핵심 텍스트 및 레이블 | 정보 명확성 |

**타이포그래피:**
*   **Font Family:** Inter 또는 Montserrat (산세리프 계열, 모던하고 기술적인 느낌 강조)
*   **Hierarchy:** H1 (KPI 제목): Bold, 크기 28px 이상 / KPI 값: Extra-Bold, 크기 48px 이상 / 설명 텍스트: Regular, 크기 14px

## 2. 최종 Mockup 레이아웃 설계 (A/B 비교 프레임워크)

**레이아웃 목표:** 사용자가 한눈에 안정성과 잠재력의 균형을 인식하도록 하여, 데이터가 단순한 숫자가 아닌 **상태(State)**로 인식되게 한다.

### A. 기본 구조: 대비형 바(Bar) 레이아웃 (Primary Focus)
*   **구조:** 수평 분할 카드 디자인. 전체 카드는 딥 블루($S$)와 크림슨 레드($SWRI$)의 대각선 구분을 명확히 보여준다.
*   **좌측 영역 (시스템 안정성 $S$):** 딥 블루 배경. 데이터의 '현재 상태'와 '안정성 지표'를 배치한다.
    *   *시각적 요소:* 차분하고 견고한 디자인.
*   **우측 영역 (수익 잠재력 $SWRI$):** 크림슨 레드 강조 영역. 데이터의 '잠재적 기회'와 '달성 목표치'를 배치한다.
    *   *시각적 요소:* 강렬하고 주목도 높은 디자인.

### B. 데이터 필드 배치 (Data Fields Mapping)

| 섹션 | 필드명 (데이터 스키마 매핑) | 시각화 방식 | 강조 색상 | 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **Header** | KPI Title (`kpi_title`) | 대문자, 중앙 정렬 | `#1A202C` | 핵심 지표 명시 |
| **Core Metric** | Stability Score ($S$) | 매우 큰 숫자 (Primary Font) | 딥 블루 배경 위에 흰색 텍스트 | 현재 시스템 안정성 시각화 |
| **Potential Metric** | Potential Gain ($SWRI$) | 대비되는 색상 (Accent Font) | 크림슨 레드 강조 | 잠재적 수익 기회 시각화 |
| **Contextual Data** | Input Log Reference | 작은 텍스트, 하단 배치 | Neutral Gray | 데이터 출처 및 맥락 제공 |
| **Visualization** | $S$ vs $SWRI$ Gauge | 도넛 차트 또는 게이지 바 | 색상 경계선으로 구분 | 두 지표 간의 상대적 관계 즉각 인지 |

## 3. 개발팀 전달용 최종 데이터 필드 명세 (Schema Mapping)

개발팀이 실제 데이터를 매핑할 수 있도록, `kpi_card_data_schema_sync.md`를 기반으로 Mockup에 필요한 **필수 데이터 필드**를 확정합니다.

**파일 경로:** `sessions/2026-05-23T11-21/designer.md` 및 `kpi_card_data_schema_sync.md` 참조 완료.

| 필드명 (Schema Key) | 데이터 타입 | 필수 여부 | 설명 | 시각화 역할 |
| :--- | :--- | :--- | :--- | :--- |
| `kpi_title` | String | 필수 | KPI 카드 제목 (예: 'API Ingestion Log') | Header 텍스트 |
| `stability_score_S` | Float (0.0 - 1.0) | 필수 | 시스템 안정성 지표 ($S$) 값 | 좌측 블루 영역 채움 정도 |
| `potential_gain_SWRI` | Float (0.0 - 1.0) | 필수 | 수익 잠재력 지표 ($SWRI$) 값 | 우측 레드 영역 채움 정도 |
| `ingestion_count` | Integer | 필수 | 이번 주기 동안 처리된 로그 수 | 상세 데이터 필드 |
| `error_rate` | Float (0.0 - 1.0) | 선택 | 발생한 오류율 ($S$의 역상) | 경고 표시 (Red Flag) |
| `contextual_link` | String | 선택 | 관련 API 엔드포인트 링크 | 하단 정보 제공 |
