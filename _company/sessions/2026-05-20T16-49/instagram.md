2.  **최우선 작업 결정:** 실제 로그 데이터 부재 문제를 해결하고, 데이터가 확보되었을 때 즉시 분석할 수 있도록 **데이터 파이프라인의 입력 조건 및 구조를 확정**하는 것을 최우선 작업으로 결정합니다.

### 📝 준비된 실행 계획 (Researcher 대비)

다음은 행동 로그 데이터를 성공적으로 수집하고 정리하기 위한 사전 준비 단계입니다.

1.  **데이터 수집 트리거 정의:** 영상이 업로드되는 즉시, 또는 특정 시간 간격(예: 24시간 후)으로 데이터 파이프라인을 자동 실행하도록 트리거 로직을 설정합니다.
2.  **로그 구조 확정:** Researcher가 필요로 하는 행동 로그의 정확한 필드(도달 수, 참여율, 시청 지속률, 좋아요/댓글 분포 등)를 명확히 정의하는 스키마를 작성하여 데이터 파이프라인에 반영할 준비를 합니다.
3.  **분석 결과 포맷 확정:** 최종적으로 Researcher에게 제공될 데이터의 정제된 형식(예: CSV 또는 JSON 포맷)을 확정하고, 이 포맷에 맞춰 로그 데이터를 정리하는 중간 단계를 설계합니다.
