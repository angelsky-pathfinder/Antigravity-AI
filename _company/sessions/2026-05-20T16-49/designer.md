연구자로부터 행동 로그 기반의 상관관계 분석 결과를 받기 전이므로, 현재 확보된 $S$와 $SWRI$를 기반으로 행동 로그 데이터를 통합하기 위한 **새로운 시각화 레이아웃 구조 및 상태 매핑 규칙(Visual System)**을 설계하여 디자인 프레임워크를 준비하겠습니다.

이는 데이터가 주입될 때 즉시 적용할 수 있는 유연한 시스템 아키텍처를 구축하는 데 중점을 둡니다.

## Blueprint & Resilience 대시보드: 행동 로그 통합 시각화 시스템 (V2)

기존의 $S$와 $SWRI$ 상관관계 시각화 위에, **행동 로그(Behavior Logs)** 데이터를 '복원력(Resilience)' 차원의 세부 지표로 계층화하여 통합합니다.

### 1. 새로운 데이터 레이어 정의: 행동 로그 (Behavior Log Layer)

기존의 상위 레이어($S$와 $SWRI$) 아래에, **행동 로그**를 별도의 시각적 계층으로 삽입합니다.

| 레이어 명 | 목표 지표 | 기반 데이터 | 색상 역할 (예시) | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **Level 1: 안정성 (Stability)** | $S$ (시스템 안정성) | 시스템 내부 측정값 | 파란색 계열 (신뢰, 기반) | 시스템의 구조적 견고함. |
| **Level 2: 수익 (Revenue)** | $SWRI$ (수익 상관관계) | 비즈니스 성과 지표 | 녹색/황색 계열 (성장, 기회) | 투자 대비 성과 측정. |
| **Level 3: 행동 (Behavior)** | $B_{log}$ (행동 로그 지표) | 사용자 상호작용 데이터 | 주황색/빨간색 계열 (주의, 피드백) | 실제 사용자의 반응과 경로 추적. |

### 2. 상태 매핑 규칙 (State Mapping Rules)

기존의 $S$와 $SWRI$에 더하여, 행동 로그($B_{log}$) 데이터를 통합할 때 **상태(State)**를 세분화합니다.

| 상태 이름 | 조건 정의 (예시) | 시각적 의미 | 색상 매핑 (Primary/Secondary) |
| :--- | :--- | :--- | :--- |
| **Optimal (최적)** | $S$와 $SWRI$가 모두 임계값 내에 있고, $B_{log}$의 평균 참여율이 목표치 이상. | 시스템이 안정적으로 성장 중. | Primary: Deep Blue, Secondary: Bright Green |
| **Warning (경고)** | $S$가 경계선 근처이며, 특정 행동 로그 지표($B_{log}$)가 임계값($B_{\min}, B_{\max}$)을 벗어나는 경우. | 잠재적 위험 감지. 즉각적인 검토 필요. | Primary: Amber, Secondary: Orange |
| **Risk (위험)** | $S$가 위험 임계값을 초과하거나, 부정적인 행동 로그 패턴($B_{log}$의 급격한 하락)이 포착된 경우. | 시스템 안정성이 위협받고 있음. | Primary: Red, Secondary: Dark Red |
| **Stagnant (정체)** | $S$는 양호하나, $SWRI$ 성장이 둔화되고, 사용자 행동 로그($B_{log}$)가 정체된 상태. | 성장 동력 상실. 개선 필요. | Primary: Gray, Secondary: Light Gray |

### 3. 레이아웃 및 시각화 설계 (Layout & Visualization Design)

**A. 메인 대시보드 구조 (The Tri-Layer View)**

1.  **상단 헤더:** $S$와 $SWRI$의 실시간 추이 그래프를 배치하여 전체 시스템 상태(Level 1, Level 2)를 즉각 파악하게 합니다.
    *   $S$는 왼쪽 상단에 위치시키고, $SWRI$는 오른쪽 상단에 위치시켜 두 핵심 지표 간의 관계를 시각적으로 강조합니다. (기존 설계 유지)

2.  **중앙 패널: 행동 로그 통합 영역 (The Behavior Deep Dive)**
    *   이 중앙 섹션은 **Level 3: 행동($B_{log}$)** 데이터를 배치하는 공간입니다.
    *   **레이아웃:** 삼분할(Three-Pane Layout)을 사용하여 행동 로그를 세 가지 핵심 차원으로 분리합니다.
        *   **차원 1 (Engagement):** 사용자 참여율($B_{log}$ 평균), 클릭률 추이, 체류 시간 분포. $\rightarrow$ *행동의 깊이 측정.*
        *   **차원 2 (Flow):** 사용자의 콘텐츠 소비 경로(Path) 시각화. $\rightarrow$ *사용자의 여정 분석.*
        *   **차원 3 (Resilience Impact):** 행동 변화가 $S$와 $SWRI$에 미치는 영향의 상관관계($B_{log}$ vs $S/SWRI$). $\rightarrow$ *결과 예측.*

**B. 상태 기반 영역 색상 매핑 적용 (Applying State-Based Coloring)**

기존의 **상태 기반 영역 색상 규칙**을 Level 3 데이터에 확장 적용합니다.

*   **'Warning' 상태 활성화:** 만약 $B_{log}$의 특정 지표(예: 이탈률)가 경고 임계값을 초과하면, 해당 영역(예: Engagement 패널) 전체 배경색이 **Amber/Orange**로 즉시 전환됩니다.
*   **'Risk' 상태 발동:** $S$ 또는 $SWRI$가 'Risk' 상태에 진입하면, 행동 로그 데이터는 자동으로 **Red** 계열의 대비 색상으로 강조되며, 가장 위험한 행동 패턴(예: 급격한 이탈)이 빨간색으로 플래그 처리됩니다.

### 4. 최종 디자인 가이드라인 (Design Guidelines Summary)

| 요소 | 세부 지침 | 적용 규칙 |
| :--- | :--- | :--- |
| **컬러 팔레트** | 기존의 $S$/$SWRI$ 색상(Blue/Green)을 기반으로, 행동 로그($B_{log}$)는 경고 및 위험에 따라 Amber/Red 계열을 동적으로 사용. | 상태 매핑 규칙에 따른 동적 색상 변환 필수. |
| **타이포그래피** | 핵심 지표($S, SWRI$)는 크고 굵게(Bold) 유지. 행동 로그 데이터는 보조적인 정보로 처리하여 시각적 계층을 명확히 함. | Hierarchy: Level 1 > Level 2 > Level 3 (행동). |
| **레이아웃** | 중앙 패널은 데이터의 **상호작용성(Interactivity)**을 극대화하도록 인터랙티브 위젯 형태로 구성. | $B_{log}$는 정적인 차트가 아닌, 마우스 오버 시 상세 행동 로그 팝업으로 연결되도록 설계. |
