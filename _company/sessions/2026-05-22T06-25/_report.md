CEO 지시 사항을 확인했습니다. 시스템 안정성($S$)과 수익 지표($SWRI$) 간의 상관관계 계산 로직 및 Circuit Breaker 조건을 최종 확정하고, 이를 실시간으로 반영하는 백엔드 API 구현 준비를 완료하겠습니다.

이는 지난 자율 사이클에서 확보한 '데이터 파이프라인 복원력 감사' PoC와 시스템 구조 설명을 기반으로 합니다. 명세가 완벽해야 다음 단계인 백엔드 API 개발의 신뢰도가 보장됩니다.

현재 메모리 및 이전 작업 기록을 바탕으로, 필요한 구현 명세를 정리하고 API 준비를 위한 계획을 수립하겠습니다.

### 1. $S$와 $SWRI$ 상관관계 로직 및 Circuit Breaker 조건 최종 확정 (Specification)

이 섹션은 백엔드 로직 구현의 계약서 역할을 합니다.

```markdown
## 시스템 안정성($S$) 및 수익 지표($SWRI$) 연동 로직 명세

### 1. 핵심 변수 정의
- $S$: 시스템 안정성 지표 (System Stability Metric). 데이터 파이프라인의 무결성, 응답 시간, 에러율 등을 종합하여 정규화된 값으로 산출한다. (범위: [0, 100])
- $SWRI$: 수익 지표 (Revenue Index). 시스템 안정성에 따라 추론된 잠재적 수익 기여도를 나타낸다. (범위: [0, 100])

### 2. 상관관계 계산 로직
- **목표**: $S$와 $SWRI$ 간의 비선형적(Non-linear) 관계를 모델링하여, 단순 선형 상관관계를 넘어 시스템 안정성이 수익에 미치는 실제 영향을 반영한다.
- **계산 방식**: $\text{Correlation}(S, SWRI) = f(S, \text{Historical\_Data}, \text{Market\_Volatility})$
    - 초기 단계에서는 단순 회귀 분석($R^2$)을 사용하되, 다음 단계에서는 외부 변수(시장 변동성, 사용자 트래픽 변화 등)를 가중치로 포함하는 다변량 회귀 모델을 적용한다.
- **실시간 반영**: API 호출 시, 최신 $S$와 $SWRI$ 값은 실시간 데이터 스트림에서 가져오며, 상관관계 계수는 주기적으로(예: 1시간마다) 재계산하여 시스템에 업데이트된다.

### 3. Circuit Breaker 조건 명세
- **목표**: 시스템 안정성($S$)이 임계치를 벗어날 경우, 수익 지표($SWRI$)의 변동성을 제어하고 잠재적 손실을 방지한다.
- **트리거 조건**:
    1. **$S$ 경고**: $S < S_{\text{threshold\_low}}$ (예: 30)일 때 Circuit Breaker를 'Open' 상태로 전환한다.
    2. **$SWRI$ 위험**: $SWRI$의 변화율($\Delta SWRI / \Delta t$)이 특정 임계치($\text{Rate}_{\text{risk}}$)를 초과할 때 즉시 경고 플래그를 활성화한다.
- **작동 방식**:
    - 만약 $S$가 낮아지면, 시스템은 잠재적 수익 창출 활동(예: API 호출 제한, 데이터 처리 속도 조절)을 자동으로 둔화시킨다.
    - 이는 백엔드에서 $S$ 값을 기준으로 API 응답 지연 시간이나 트랜잭션 성공률에 영향을 미치는 내부 게이트를 설정하는 것으로 구현된다.

### 4. 백엔드 API 요구사항 (FSD 기반)
- **API Endpoint**: `/api/metrics/realtime`
    - **Request**: `{"query": "S_SWRI_correlation", "timeframe": "last_hour"}`
    - **Response**: `{ "S_SWRI_correlation": value, "current_S": value, "current_SWRI": value, "breaker_status": "OPEN/CLOSED", "reason": "..." }`
- **데이터 흐름**: 시스템 안정성 및 수익 지표의 실시간 변화는 데이터 파이프라인에서 집계된 후, 이 결과가 $FSD$에 명시된 구조를 따라 API로 제공되어야 한다.

---
```
