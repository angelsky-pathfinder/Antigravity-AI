# 🚀 Pathfinder: $S$ & $SWRI$ 시각화 시스템 최종 실행 사양서 (V1.0)

**문서 목적:** 시스템 안정성($S$) 및 수익 지표($SWRI$) 변화에 반응하는 대시보드 UI/UX의 모든 시각적, 상호작용 가이드라인을 개발팀이 즉시 프론트엔드 구현에 사용할 수 있도록 최종 확정한다.

**핵심 컨셉:** **'위험 기반의 부드러운 피드백 (Risk-Based Gentle Feedback)'**
시스템 안정성($S$) 감소 시에는 경고 메시지를 통해 잠재적 위험을 알리되, 사용자에게 혼란을 주지 않기 위해 애니메이션과 색상 변화를 통해 '안정화' 및 '주의' 상태를 부드럽게 전달한다. 수익 지표($SWRI$) 과열 시에는 즉각적인 행동 유도를 위해 명확한 경고와 대비 효과를 사용한다.

## 1. 핵심 시각화 변수 매핑 (Color Mapping & Thresholds)

| 지표 | 상태 범위 | 색상 코드 (HEX) | 애니메이션/효과 | 경고 메시지 (UI Text) |
| :--- | :--- | :--- | :--- | :--- |
| **시스템 안정성 ($S$)** | $S > 85\%$ (안정) | `#4CAF50` (Green) | 부드러운 페이드 인/아웃 (300ms). 미세한 녹색 맥동. | "시스템 안정 상태: 정상" |
| | $60\% < S \le 85\%$ (주의) | `#FFC107` (Amber/Yellow) | 느린 깜박임(Pulse) 애니메이션. 배경에 은은한 노란색 오버레이. | "⚠️ 시스템 안정성 주의: 잠재적 불안정" |
| | $S \le 60\%$ (위험) | `#F44336` (Red) | 빠른 플래시(Flash, 150ms). 경고 아이콘 강조. 배경에 붉은색 경고 박스 오버레이. | "🚨 시스템 안정성 위험: 즉각적인 점검 필요" |
| **수익 지표 ($SWRI$)** | $SWRI > 120\%$ (과열) | `#FF9800` (Orange) | 미세한 떨림(Tremble) 애니메이션. 대비 강한 주황색 배경 강조. | "📈 수익 지표 과열: 자원 분배 점검" |
| | $80\% < SWRI \le 120\%$ (경고) | `#FFEB3B` (Light Yellow) | 느린 깜박임(Pulse). 경고 아이콘 표시. | "⚠️ 수익 지표 주의: 수익성 모니터링 필요" |
| | $SWRI \le 80\%$ (위험) | `#D32F2F` (Deep Red) | 빠른 플래시 및 강한 대비 효과. 빨간색 경고 박스 강조. | "🛑 수익 지표 위험: 비즈니스 리스크 발생" |

## 2. 애니메이션 가이드라인 (Animation Guidelines)

**A. $S$ 변화 시 애니메이션:**
1.  **안정 상태 ($S > 85\%$):** 데이터는 부드럽게 녹색으로 전환되며, 배경은 안정적인 녹색 계열로 페이드 인/아웃 처리합니다. (Transition: `ease-in-out` over 300ms)
2.  **주의 상태 ($60\% < S \le 85\%$):** 데이터는 노란색으로 전환되며, 배경에 미세한 노란색 오버레이가 적용됩니다. 변화는 느리고 부드럽게 진행되어 사용자가 정보를 인식할 시간을 제공합니다. (Transition: `ease-in` over 500ms)
3.  **위험 상태 ($S \le 60\%$):** 즉각적인 주의를 위해 데이터는 붉은색으로 전환되며, 전체 카드에 대해 짧고 강렬한 플래시 효과(150ms)와 함께 경고 아이콘이 중앙에 크게 표시됩니다. (Transition: `linear` over 150ms)

**B. $SWRI$ 변화 시 애니메이션:**
1.  **과열 상태 ($SWRI > 120\%$):** 지표 배경은 주황색으로 강조되며, 데이터는 미세하게 떨리는(Tremble) 효과를 적용하여 '과열' 상태임을 시각적으로 암시합니다. (Effect: CSS `animation: tremble 0.5s infinite;`)
2.  **위험 상태 ($SWRI \le 80\%$):** 배경은 짙은 빨간색으로 전환되며, 이는 즉각적인 조치가 필요함을 나타내기 위해 강한 대비를 사용합니다. (Effect: 강한 색상 변경 및 경고 박스 표시)

## 3. 최종 시각화 레이아웃 사양 (Layout Specifications)

**A. 대시보드 메인 패널 구조:**
*   **레이아웃:** 2열(Two-Column) 또는 그리드 기반으로 구성하여, $S$와 $SWRI$를 상단에 배치하고 나머지 영역에 세부 지표 및 액션 항목을 배치합니다.
*   **$S$ 표시 위치:** 대시보드의 최상단 중앙에 가장 큰 폰트 크기로 표시하며, 해당 지표가 전체 시스템 상태의 핵심임을 강조합니다. (위에서 정의된 색상 매핑 적용)
*   **$SWRI$ 표시 위치:** $S$ 지표 바로 아래 또는 인접한 섹션에 배치하여 상호 연관성을 시각적으로 연결합니다.

**B. 경고 메시지 및 CTA 통합:**
1.  **경고 메시지 (Warning Message):** 각 $S, SWRI$ 카드 옆에 **작은 아이콘(⚠️/🚨)**과 함께 1단계에서 정의된 텍스트를 명확히 표시합니다.
2.  **실행 가능한 CTA (Actionable CTA):** 위험 상태($S \le 60\%$ 또는 $SWRI \le 80\%$)가 감지될 경우, 해당 지표 카드 하단에 **"즉각 점검하기"** 버튼을 활성화하며, 이 버튼 클릭 시 관련 디버깅 로그 페이지로 이동하도록 연결합니다. (이동 경로: `Dashboard > Risk_Review` 또는 `Log_View`)

**C. 유튜브 도입부 비주얼 시안 제안 (Designer Input):**
*   **컨셉:** 'Blueprint'와 '복원력(Resilience)'을 극대화하여, 데이터의 불안정성이 어떻게 관리되는지를 보여줍니다.
*   **프레임별 레이아웃 제안:**
    *   **Frame 1 (문제 제기):** 화면 전체에 흐릿한 불안정한 노이즈/파형 애니메이션. 중앙에 큰 빨간색 경고 아이콘(`🚨`)과 함께 "시스템 안정성($S$)은 어떻게 관리될까?"라는 질문 제시. (배경: 어둡거나 차가운 블루 톤)
    *   **Frame 2 (해결책 소개):** $S$와 $SWRI$의 데이터 흐름을 나타내는 깔끔한 다이어그램(Blueprint 스타일). 안정성($S$)은 녹색으로, 수익($SWRI$)은 주황색으로 명확히 구분하여 시각화.
    *   **Frame 3 (결론/권위):** 핵심 메시지('Blueprint' 기반의 복원력 관리)를 강조하며, 최종적인 해결책(시스템 안정성 확보)을 자신감 있게 제시. (색상: 신뢰감을 주는 짙은 네이비/골드 조합)
