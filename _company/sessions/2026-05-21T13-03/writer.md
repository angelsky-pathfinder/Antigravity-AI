# Blueprint & Resilience 대시보드 운영 매뉴얼 (실행 가이드)

본 문서는 Designer가 확정한 'Blueprint & Resilience' 대시보드의 시각적 설계 원칙을 기반으로, 시스템 안정성($S$)과 수익 지표($SWRI$)를 실시간으로 반영하는 운영 및 애니메이션 적용 방안을 명확히 제시합니다. 이 가이드는 개발팀(Designer) 및 프론트엔드 구현에 직접 사용됩니다.

## 1. 비주얼 시스템 개요 (Visual System Overview)

대시보드의 핵심 목표는 사용자에게 **현재 상태의 안정성과 잠재 수익 기회**를 직관적으로 전달하는 것입니다.

### 1.1. 핵심 컬러 팔레트 (The Core Palette)
시스템 전체에 일관성을 부여하며, 각 색상은 명확한 의미를 내포해야 합니다.

| 역할 | 색상 코드 | 상징하는 개념 | 적용 범위 |
| :--- | :--- | :--- | :--- |
| **Primary Color (안정성)** | `Deep Blue (#004D99)` | 시스템 안정성($S$) 및 신뢰 | 대시보드 배경, 주요 지표 표시 |
| **Accent Color (잠재력)** | `Crimson Red (#CC3333)` | Premium Bundle 및 잠재 수익 기회 강조 | 업그레이드 경로, 수익 관련 지표 하이라이트 |
| **Base Color (구조)** | `Cream/Off-White (#F5F5F5)` | 미니멀하고 명확한 구조 제공 | 텍스트 영역, 카드 배경 |

### 1.2. 타이포그래피 가이드라인 (Typography Hierarchy)
정보의 중요도에 따라 시각적 계층 구조를 확립하여 인지 부하를 최소화합니다.

*   **Headline (Blueprint Title):** Montserrat Bold, 48pt 이상
    *   목표: 대시보드의 핵심 목표(Blueprint/Resilience)를 강력하게 제시.
*   **Metric Value (S/SWRI):** Roboto Mono, 36pt
    *   목표: 시스템 안정성($S$) 및 수익 지표($SWRI$)와 같은 수치에 시각적 무게를 부여하여 즉각적인 집중 유도.
*   **Narrative Text:** Inter, 16pt
    *   목표: 복잡한 데이터의 해석을 돕는 명확하고 읽기 쉬운 설명 제공.

## 2. Tier별 비주얼 매핑 테이블 (Visual Mapping Table)

각 사용자가 선택한 티어(Tier)에 따라 대시보드의 색상과 강조 방식이 동적으로 변화해야 합니다.

| Tier | 핵심 목표 | Primary Color 적용 | Accent Color 적용 | 상태 시각화 전략 |
| :--- | :--- | :--- | :--- | :--- |
| **Standard Tier** | 명확성/구조 확보 | Deep Blue (Primary) | Cream (Base) | 정적이고 구조적인 레이아웃 유지. 데이터는 안정적으로 표시. |
| **Premium Bundle** | 잠재력 및 수익 강조 | Crimson Red (Accent) | Deep Blue (Secondary) | 활성화 상태: 빨간색 하이라이트와 동적 효과를 사용하여 기회(Opportunity)를 즉각적으로 부각. |
| **Resilience State** | 시스템 안정성 극대화 | Deep Blue (Primary) | 없음 (단일 집중) | 경고/안정: 딥 블루 배경에 미세한 파동 애니메이션을 적용하여 시스템의 '견고함'을 표현. |

## 3. 상태 변화 애니메이션 가이드라인 (State Transition Animation Guidelines)

시스템의 상태 변화를 시각적으로 명확하게 전달하여 사용자의 인지 부하를 최소화하는 동적 규칙입니다.

### 3.1. 안정성 모니터링 ($S$ 지표 기반)
*   **임계치 도달 시:** $S$ 지표가 사전에 설정된 임계치를 벗어날 경우, 배경 색상이 **Deep Blue에서 경고색(주황/레드)**으로 즉시 전환되어야 합니다.
*   **애니메이션 적용:** 이 상태 변화는 단순한 색상 변경이 아닌, 미세한 **파동 애니메이션**을 동반하여 시스템의 불안정성을 시각적으로 강조해야 합니다.

### 3.2. 티어 업그레이드 시
*   사용자가 Standard에서 Premium Bundle로 전환할 경우, 대시보드의 주요 요소(KPI 카드 등)에 **Crimson Red Accent Color**가 활성화되어야 합니다.
*   **동적 효과:** 이 전환은 단순한 색상 변화를 넘어, 잠재력 강조를 위해 부드러우면서도 강렬한 시각적 효과(예: 페이드 인/아웃 또는 그라데이션 변화)를 적용하여 사용자의 행동을 유도해야 합니다.
