# KPI 카드 디자인 시스템 최종 명세 및 레이아웃 좌표 (개발용)\n\n## 1. 디자인 원칙 (Blueprint & Resilience Framework)\n- **핵심 컨셉:** 위험으로부터 비즈니스를 보호하는 '복원력(Resilience)'과 기술적 안정성($S$)을 시각적으로 표현합니다.\n- **컬러 전략:** \n  - **Primary (안정성/기술):** Deep Blue (\#004D99) - 신뢰, 기술적 안정성\n  - **Accent (경고/성과):** Crimson Red (\#CC3333) - 긴급성, 핵심 성과 지표($S$)\n- **레이아웃 원칙:** 시각적 흐름(Visual Flow)에 따라 정보의 중요도 순으로 계층화하며, 대비를 통해 안정성과 경고를 즉각적으로 구분합니다.\n\n## 2. KPI 카드 레이아웃 좌표 및 명세 (API 검증 적용)\nKPI 카드는 API 입력값 검증 결과($S$와 $SWRI$)를 표시하는 데 사용됩니다. 모든 좌표는 반응형 디자인을 고려하여 상대적 비율로 정의합니다.\n\n### A. 전체 카드 구조\n- **Card Type:** Standard Metric Card (2 Columns / 1 Row)\n- **Width:** 100% (반응형 환경에서 유연하게 조정)\n- **Height Ratio:** 1:1.5 (세로 정보 강조)\n\n### B. 핵심 요소 좌표\n| Element | Description | Relative Position (Percentage) | Color/Style Reference |
| :--- | :--- | :--- | :--- |
| **Header Bar** | 카드 제목 및 상태 표시 영역 | Top 10% | Deep Blue 배경, White Text |
| **Metric Value ($S$)** | 시스템 안정성 지표 (핵심) | Left: 35%, Center: 40% | Crimson Red (Accent), Bold Font Size\n| **Metric Value ($SWRI$)** | 수익 지표 (보조) | Right: 25%, Center: 40% | Deep Blue (Secondary Text)\n| **Status Indicator** | 실시간 상태 표시 (예: PASS/FAIL) | Top Right Corner | Conditional: Green (PASS) / Red (FAIL)\n| **Data Visualization Area** | 실제 데이터 시각화 영역\n| **Footer Bar** | 데이터 출처 및 버전 정보\n- **Version Stamp** | Bottom 10% | Light Gray Background, Small Font Size\n\n## 3. 개발팀 전달 가이드라인 (Visual Consistency Enforcement)\n1. **Color Mapping:** 모든 $S$ 지표는 Crimson Red로 강조하고, $SWRI$ 지표는 Deep Blue로 명확히 구분하여 데이터의 성격을 즉각적으로 인지할 수 있도록 합니다.\n2. **Layout Implementation:** 레이아웃 좌표를 기준으로 CSS Grid 또는 Flexbox를 사용하여 구현하며, 특히 헤더 바와 데이터 영역 간의 대비(Contrast)를 최우선으로 확보해야 합니다.\n3. **Consistency Check:** 모든 KPI 카드 Mockup 및 최종 구현 시, 이 명세서에 정의된 색상 코드(\#004D99, \#CC3333)와 레이아웃 비율을 100% 준수하도록 검증 로직을 삽입해야 합니다.\n\n**[참고: 실제 CSS/React 구현 시 필요한 핵심 변수]\n- `primaryColor`: #004D99 (Deep Blue)\n- `dangerColor`: #CC3333 (Crimson Red)\n- `stabilityMetric`: $S$ 지표가 빨간색으로 강조되어야 함.\n\n**[최종 확인]** 이 명세는 기술적 실행과 시각적 일관성을 완벽하게 매핑합니다. 개발팀은 이 문서를 기반으로 API 검증 로직에 적용될 KPI 카드 디자인 시스템을 구현할 수 있습니다.\n
